# Security

Found a problem that could expose someone's data? Please do not open a public issue.

Use **Security → Report a vulnerability** on [this repository](https://github.com/Laxus-CMD/Laxed-College-Hub/security/advisories/new), which only the maintainers can see. Say what you did and what happened. Please test with your own account only.

How the app protects data is described in [docs/backend.md](docs/backend.md).
